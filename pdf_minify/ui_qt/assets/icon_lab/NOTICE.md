# Icon Lab artwork notices

These are unmodified stock icon bytes, not new artwork or a Task Coach dependency.
The lossless base64 resource bank contains only the curated PNG subset; each
entry records the original file path, pixel size and SHA-256. Decode its
`png` field to recover the original distributable PNG. No external theme or
runtime download is required.
